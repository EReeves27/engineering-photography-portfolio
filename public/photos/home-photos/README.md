# Home page gallery

All images in this folder appear automatically on the photography **Home** page (scroll waterfall).

Supported: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.heic`, `.bmp`, `.tif`

After adding or removing files:

- **Local dev:** save any file or restart `npm run dev` (Vite rescans this folder).
- **GitHub Pages:** push and let the deploy workflow run a fresh build.
